📋 Como preencher e enviar a ficha AGHUse

  1. Preencha todo o formulário abaixo.
    1.1 Complete todos os campos obrigatórios do formulario com atenção.
    1.2 Clique em “Gerar PDF”.
    1.3 O sistema vai criar um arquivo com os dados preenchidos.
  2. Assine o PDF gerado:
    2.1 Se você tem assinatura eletrônica, assine o arquivo diretamente no computador ou celular.
    2.2 Se não tiver assinatura eletrônica, envie o arquivo e compareça à Seção AGHUse para assinar a ficha impressa.
  3. Envie o PDF por e-mail para:
    3.1 📧 suporteaghuse@hmab.eb.mil.br
